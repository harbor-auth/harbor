# private-harbor-sign-in-button-kit

Official "Sign in with Private Harbor" button + brand kit for relying-party (RP) websites: accessible SVG assets, copy-paste HTML/CSS, a dependency-light React component, a minimal executable RP integration example, and OIDC/security/brand documentation — published as a standalone, permissively-licensed package (`sdk/sign-in-button/`) outside the AGPL boundary.
